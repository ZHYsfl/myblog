AI-Whys 新增了 AI Agents 篇！成为继 DL（含延伸 audio-dl）、RL 后的宏观第三大模块！除此之外，还修复了 RL 插图的一些小错误。

作为当红炸子鸡的 AI Agents，是一个工程壁垒极高的领域。比如在做 RL Infra 时，不同模型往往需要写特定的 parser，模型的训推需要保持严格一致；如果不透彻理解 agentic RL 和 AI Agent 的底层逻辑，根本无从下手。基于这个认知，AI-Whys 整理了 Agent 的底层理论（如图 1）。

图 1 展示了 RL 轨迹的 S/A/R 如何和 LLM 多轮调用的 input/output 对应起来：一次 LLM call 是 policy 在 state 下采样 action，tool response 回填上下文形成下一个 state，最终回答让 episode done，然后 credit assignment 并 update。这把 Agent 从“聊天 + 工具”变成了“可采样、可训练的策略交互过程”。

最新的宏观全景图（图 2，高清大图见文末 URL，源码见文末 URL）也可以看到，AI Agents 本质上就是从 online RL 和 Transformer 中长出来的。

纸上得来终觉浅。AI-Whys 深知仅了解理论的不足，所以也开源了实验 42：Go 和 Python 两个语言版本的 AI Agent lightweight framework（后续还会加上 TS 语言版本），支持流式推理、并行工具调用、watchdog 限时推理、三种记忆机制。

By the way，我的 VoxFlow 全双工多模态实时交互级联 Agent 系统（技术报告详见文末 URL），就长在自己搭建的 Go 语言这个 framework 的 plus 版本下。
