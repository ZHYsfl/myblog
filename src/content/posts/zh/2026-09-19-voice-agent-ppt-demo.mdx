This is a real-time interactive presentation system involving a human, a voice agent (a cascaded solution), and other agents. In this demo, we just use a PPT agent as an example; in the future, we can add more agents. In just a few minutes, we can use this system to create a PPT, and at any time we can talk to the voice agent to revise the PPT as we want.
